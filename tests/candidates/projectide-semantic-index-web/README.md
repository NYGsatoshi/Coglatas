## Exact evidence admission

The runner requires one original source file, one describe group and all 24
literal full case identities. Genuine Vitest reports count that file and describe
group as two suites. Counters, status, exact raw physical file path, fullName,
ancestorTitles and title must agree; foreign, repeated, skipped, pending, todo,
failed or contradictory cases are rejected. Duplicate JSON object keys,
nonfinite values and unexpected snapshot/error information cannot be ignored.
The original process must exit successfully independently of reported counters.

The runner checks actual source bytes and regular-file mode, staged blob,
immutable Product HEAD, exact single-path staged delta, empty unstaged tracked
delta and absence of unexpected untracked inputs after composition and after
every external command. Git subprocesses exclude inherited `GIT_*` overrides;
ordinary host/runtime variables and the caller environment remain unchanged.
An existing candidate destination or dirty independent checkout is refused.
Untracked inventory uses NUL-separated paths and includes Git-ignored source
and configuration, including declarations under `frontend/src/**/data/`.
Initial composition and version checks permit no generated files. Only the
exact `frontend/node_modules/` subtree is admitted after `npm ci`; the actual
`frontend/.angular/cache/` subtree is additionally admitted after Angular tests.
Nested dependency/cache names and other ignored paths remain refused.

After genuine Angular execution, 22 controls include 19 that replay its original retained JSON
and receipt plus disposable real Git repositories. They exercise malformed
counters, identities, paths, failures, snapshots, duplicate/nonfinite JSON,
source/index/mode/HEAD/Product drift, untracked inputs, nonzero commands and Git
environment redirection. Controlled process responses are verifier tests only.
Three additional disposable-Git controls independently verify ignored compiler
input refusal, nested output-name refusal and phase-specific output admission.
Those three controls also run locally without fabricating a native receipt.
The control report and `ANGULAR_ADMISSION_CONTROLS_COMPLETE` marker bind the
unchanged original Vitest SHA256 and grant no new Angular execution credit.
