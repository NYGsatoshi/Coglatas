# Owned local regional predicate observation host

This bounded #1034 Product continuation gives actual regional predicate
observation a separate predeclared local request, manifest, attempt response
and paired recording receipt. It uses the existing
[regional Compiler observer](projectide-regional-predicate-observation.md)
without replay or additional regional executions. Existing normal, output,
Proof-array, initial-root observation and pass host protocols remain unchanged.

## Declare the exact local execution

RegionalPredicateObservationCompilerHostRequest binds the existing Core execution
and materialization digests plus all four predeclared capture dimensions: mode,
evaluation limit, node limit and operator-body byte limit. Manifest remains the
default. The regional policy/hash domains and ActualRegionalEvaluationsOnly
scope are distinct from initial-root observation even for the same Core request.
Client generation is bound separately by the exact request and declaration;
the older Core digest is unchanged.

LocalRegionalPredicateObservationCompilerRecordingSession.Prepare validates the
actual input transfer and creates a local declaration before execution. It
records the input/Source/context/compiler/materialization/policy basis and
owned session/run IDs without retaining the request or compilation graph.

ExecuteAsync accepts the exact owned declaration and immutable request instance,
revalidates input before reservation, reserves a single run UUID and invokes
LocalRegionalPredicateObservationCompilerHost. Each actual attempt receives a
separate UUIDv4. The returned RegionalPredicateObservationCompilerRecordedInvocation
couples the actual response and receipt. Request/manifest/response tokens and
the exact intended manifest are checked together by IsFor(request, manifest).
A genuine older pair with equal input/result/observation digests cannot satisfy
a new intended declaration.

The direct local host can return an actual attempt response for a declaration;
only session execution performs its reservation and creates the paired receipt.
Local object ownership grants no current permission, session liveness, intended
client selection, freshness, producer trust or remote attestation.

## Original regional facts and separate result axes

Host Completed means an actual Compiler envelope was produced. Actual whole
Compiler execution, coverage, verdict, evidence completeness and capture state
remain separate in response metadata. Resource exhaustion can have a completed
host outcome and an interrupted observation. An earlier aggregate capture gap
remains distinct from later Compiler failure. Captured call/evaluation counts
are not complete execution or causal coverage.

The response binds the original whole result and regional record digests.
The receipt retains original regional observation metadata/digests without
request, response, compilation or operator maps. JsonIgnore excludes request.Core
and response.Execution from automatic serialization. Original operators remain
available only through the explicit Domain read with the exact actual whole
execution, record, region and published diagnostic objects. Equal older region
objects, root summaries and matching hashes cannot borrow a graph.

Domain records continue to label their own Compiler run identity NotAllocated:
this local host wrapper supplies its actual session/run/attempt identities
without rewriting the original Domain format. Neither initial-root evaluations
nor earlier intermediates become recorded through this regional wrapper.

## Diagnostic reruns, bounded reservation and cancellation

A diagnostic origin must be the actual earlier receipt owned by the same local
session and Core execution/materialization input. A new declared request/run
may change capture policy or client generation; changed input/materializations
cannot borrow that origin. Original run, manifest digest, receipt digest,
attempt ID and known ancestor run IDs remain explicit. A later successful
diagnostic run cannot promote the earlier Manifest or cancelled outcome.

The session retains at most32 reserved executions and31 diagnostic ancestors.
Duplicate run IDs, foreign declarations/origins, lineage cycles/overflow and
capacity exhaustion are refused. Concurrent duplicate execution reserves one
actual attempt. Preparation retains no unbounded session list of declarations.
These are local technical limits, not adopted Pin/retention/storage quotas.

Cancelled attempts have no Compiler result, observation digest or observation
metadata. Host and session recheck cancellation before publication. A retry
uses a new run/attempt linked to its actual cancelled origin. Pre-cancelled
controls do not establish deterministic mid-evaluation/disposal race timing.

Disposal prevents preparation/execution and clears session reservation metadata.
It does not physically erase already returned caller-owned metadata or frames.
