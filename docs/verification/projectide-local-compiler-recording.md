# Owned local Compiler recording foundation

Implements a bounded ProjectIDE-only part of #1034 on top of the existing local Compiler host and produced-output snapshot reader. This is an implementation format, not adoption of a normative registry or storage policy.

- Prepare a local recording manifest before executing. It binds the exact declared input/Source/context/Compiler, host execution-input digest (including snapshots, units, calendars and scope claims), client generation, chosen capture mode and byte budget.
- Execute the original caller-owned immutable host request. Revalidate transferred Source and every declared binding before reserving an identity. The session owns a LocalNetCompilerHost; it accepts no arbitrary host response or transport as a completed original run.
- Keep the actual host AttemptId distinct from the declared recording RunId and deterministic CompilerResult. Diagnostic reruns use a new RunId and actual attempt, link the actual owned original receipt/attempt, preserve the same execution-input binding and refuse ancestor identity reuse or foreign-session origins.
- Default to Manifest. Explicit AvailableOutputs captures only already produced original output bodies through the existing bounded reader. Capture gaps do not alter Compiler execution/coverage/verdict/freshness.
- Record host cancellation/unsupported/error outcomes without inventing a Compiler result or output snapshot. A separately identified diagnostic rerun may link such an actual host-only outcome; it does not impersonate the original failure or recover earlier unrecorded states.
- Manifests/receipts retain identity metadata and any explicitly captured output bodies; they retain no Source object, host request/response or CoreCompilation. The returned host response remains separately caller-owned.
- Serialize reservation, duplicate/capacity checks, disposal and receipt publication under the owned session gate. Actual compilation runs outside the gate. Disposal prevents later session publication and clears owned identity metadata; caller-owned returned objects are not physically erased.
- The initial 32-execution / 31-ancestor limits bound local identity metadata only. Exhaustion refuses execution; no silent eviction, Pin, TTL, durable retention or authorization policy is adopted. Local session identity grants no current access, Registry, Producer Trust or Evidence Eligibility.

Product tests replay all twelve actual Compiler output fixtures, preserve original Compiler results, verify distinct diagnostic origins, explicit budget gaps and absent-result host outcomes, reject transferred Source/generation/materialization substitution before reservation, and exercise snapshot scope claims, concurrent duplicate/capacity reservations and lineage limits. Work-only prototype controls are separate evidence and do not replace current Product tests, hosted CI or independent acceptance.
