# Native coverage for existing quality-evidence controls

The canonical Sonar Python producer also executes the existing Qodana
reconciliation and packet-verification unit suites. Their four operational
subjects join the existing include list; test bodies remain outside collection.
The existing exact-scope assertion retains all prior subjects and the same
equality operator, with the four authorized subjects added to its expected set.
The branch-enabled pytrace collector, process bootstrap, pinned coverage wheel,
single combine and single XML import remain unchanged.

The additional suites exercise immutable report/source identity, finding
multiplicity, reviewed correspondence, packet scope, test-result counters and
normal-merge conflict controls. They use synthetic fixtures and mocked network
responses. Their passing assertions do not establish a current full Qodana run,
approve a finding disposition or qualify a historical packet for promotion.
The original suites, assertions, packet payloads, policy, budgets and producer
subjects are preserved.

Local native reports retain original bytes, zero-hit lines and missing branch
arcs. Only a separately qualified resulting-Main analysis establishes any Main
coverage or original Quality Gate change. The collection first proposed in
#1732 is incorporated through #1677 after the earlier pilot integrations and
their resulting-Main evaluations. Local increments are not added to other PR
totals.
