# Root-bound transitive binding closure

Existing ownership: #905 under #888 / IDE-START-01, with #1032 and the shared Compiler consumers. This adds a derived binding stage needed before complete external semantic validation and IR. It does not complete #905/#1032 or relax the existing external-closure-not-lowered guard.

CompilerBindingClosure.Build takes an immutable PartialSemanticModel and the exact expected root input digest. It follows resolved entity, port and document symbol keys by full SourceRevisionContext, materializing no new data and allocating no domain/snapshot IDs. A deterministic work queue visits each reachable exact context once. Repeated EntityId/DocumentId values across Projects and multiple pinned versions remain distinct regions. A reference cycle is a bounded binding graph, not proof that a dependency/workflow/dataflow cycle is semantically allowed.

The binder now retains admitted snapshot ID/version together with its coverage-adjusted immutable Source. Closure construction uses these exact records rather than guessing a snapshot identity from a matching context/digest or equivalent manifest alias. Rejected/denied bodies do not enter that registry. The public single-Source binder's findings, symbols, references, logical operations and serialized result contracts remain unchanged.

Each dependent region uses the same root schema/compiler/descriptor/feature/engine/numeric settings, removes only its own external pin from the temporary binding input, normalizes root-only Scenario settings for the exact dependent context and takes the exact admitted Source coverage. A materialized dependent Scenario retains its actual base/overlay context and concrete Source; its original assumption intent is neither reconstructed nor replayed. The binding-only temporary model records no newly interpreted assumptions. Only the remaining shared logical-operation budget is available to that region. The original root Source is an implicit already-admitted scope for an exact back-reference; no fictitious ExternalSnapshotId/version/pin is minted. A typed value reference still requires its existing exact manifest/version binding. The temporary per-region model is internal and is not a standalone Compiler input or cache key.

Every public region certificate binds the complete root input digest, its exact Source context/digest, actual admitted snapshot identity/version, supported declaration/Relation inventory and resolved reference/finding projection. Therefore even unchanged dependency bytes have a different certificate when only the captured root changes. Derived region inputs and diagnostic identities cannot be reused apart from that root binding. Content digests are not producer attestation or current authorization.

Complete means all reached regions' declarations are supported and references are bound with complete declared Source coverage. Incomplete retains an explicit reachable prefix and its scoped findings; it is not a complete closure. StaleInput returns no regions. Shared budget exhaustion or bounded publication overflow returns ResourceLimit rather than a complete prefix. Cancellation is checked around traversal and before/after publication. Region and snapshot collection storage is owned/immutable; original Sources and settings are never modified.

This stage does not validate all units/calendars, graph-kind invariants, required predicates, Requirement eligibility, Resource capacity, execution plans or current access. The regression suite deliberately retains a false required external Constraint in a binding-complete region while actual Compiler/IR remain Inconclusive/not produced. All seven initial concepts are retained for subsequent semantic processing; they are not discarded to get PASS.

Developer controls cover transitive scopes and exact back-references, cross-Project Relation endpoints sharing the same EntityId, a missing complete-scope target, missing/denied/partial transitive supply, unsupported declarations inside a required Source, two versions of one Project, full versus cached/permuted supply equality, document references, actual applied Scenario/candidate dependency contexts, Source-encoding publication limits, stale/cancelled/shared-budget outcomes, immutable public storage and changed-root certificate invalidation. Actual LocalNetCompilerHost materialization produces the same closure as direct Core binding. These are Product regressions, not independent qualification, actual Avalonia or Windows platform acceptance.
