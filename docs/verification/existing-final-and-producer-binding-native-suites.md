# Existing final and producer binding native suites

The common pre-credential Python loop adds the existing Final Gate verifier
regressions (10 cases) and producer archive/reconciliation suite (25 cases).
The latter includes real local Git and the existing packaging shell with
synthetic assembly bytes. The supported Linux job supplies Ruby and Bash;
Windows local checks do not establish execution of all 25 cases.

These suites each appear once in the 53-entry loop. Their owned test IDs are
checked independently of module loading, duplicate IDs are rejected, and a
new load_tests hook requires a separate completeness review. Existing nested
accounting suites remain selected only by their owning evidence hook.

The 63 production subjects, pinned collector/bootstrap, raw shards, single
combine/XML import, native branch/line accounting, zero-hit ranges and test-body
exclusion remain unchanged. Original suite methods and assertions are unchanged.
Synthetic bytes and verifier tests do not approve real provenance, runtime
adapters, governance activation, RLS, recovery, security findings or Release GO.

Require supported exact-head collection and all original report/source/run/
attempt/digest mappings, CI, original PR Gate and independent review. Requalify
resulting Main denominator and actual covered-line/condition delta separately.
Local/native increments are not an additive estimate of Main improvement.
