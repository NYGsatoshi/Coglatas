offline security-helper suites. They exercise runtime argument boundaries,
synthetic assembly binding and Kafka ACL/denial observations using synthetic
data. Their three original helper modules join the seven existing subjects.

scanner import remain. Exact-set guards retain all previous entries and require
the complete expanded subject set. Test bodies remain outside measured sources.

scope is removed and no quality threshold or report byte is rewritten.

approve private attestation, promote held governance policy, dispose findings,
qualify deployed RLS or establish a release decision. Only independently measured
resulting-Main analysis can establish any Overall Coverage or Quality Gate change.
