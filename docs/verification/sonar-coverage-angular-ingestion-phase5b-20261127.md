# Phase 5b: authenticated multi-LCOV ingestion trial

Based on integrated #2278 `1b2a2f8d763a6c05435ea4976d6b877c6bc1db56` (native Angular proof #2283 merged). Exact qualification on `b00340579fa0a3639194e469bd19ac4bd1eb2f9a` [run 45913479152](https://github.com/NYGsatoshi/Coglatas/actions/runs/45913479152) proved 175 specs, 2,345 all-passed tests, 310 source files, 25,813 line points/22,015 visited and 21,143 branch points/16,205 visited. Full 388.572 s, max shard 209.262 s. The prior integrated #2278 [authenticated run 45913402906](https://github.com/NYGsatoshi/Coglatas/actions/runs/45913402906) passed on d02cc9f4, with Angular 296 s, Python 486 s, scanner 1,203 s. Its Ubuntu coverage came from its own scanner build.

This candidate replaces the original single Angular producer with three credential-free lanes using the already qualified native collector: full unfiltered baseline, shard 1/2, shard 2/2, all with the same builder and tracked inputs. A read-only join requires exact source/tree/run/attempt, artifact layout and hashes, complete disjoint test identities, and identical native LCOV source/line/branch identities and hit states. Only after this passes, copy the two original LCOV files (cmp confirms original bytes) and exact comparison receipt into the compact handoff; bind all three files via the existing independent job-output digest, reverified before scanner credentials. Scanner receives explicit two report paths, never the baseline, never a synthesized merged report. All other language paths, native Ubuntu collector, scanner begin/build/end, router, credential grants, exclusions and thresholds stay unchanged.

This is an initial **ingestion qualification**, not final production speedup: baseline deliberately remains on the critical path until the real SonarCloud import and per-file line/condition coverage equivalence are demonstrated. If that succeeds, a follow-up can decide how to remove redundant baseline execution while preserving current-source inventory and report validity. Angular alone is not the current critical path (Python and same-build Ubuntu .NET are longer). Do not claim end-to-end acceleration from the shard command duration alone.

Qualification: hosted static and ordinary CI on this PR; once admitted to a main-target staging branch, all three real native lanes and strict comparator plus original-report handoff and authenticated Sonar import; inspect scanner logs and actual Sonar coverage measures for comparable source scope, per-file lines/conditions and uncovered counts. No Main merge, no change to secret routing, no gate weakening or synthetic coverage.
