## Admission

The reader requires separately admitted current scoped Source/publication/plan and an admitted terminal simulation recording. Original controls, manifest, each snapshot, each event prefix and optional inspection are bounded and digest-checked before parsing. The manifest must equal the admitted run manifest; input, plan, controls and result digests must agree. The supported profile has at most64frames and the exact current default Core control limits/commands/points. Unknown versions, mixed runs, malformed frames and in-place Source/recording mutation refuse admission.

Frames retain increasing revisions, actual run-event prefixes, committed virtual ticks and counts. Pending transitions are distinct from the last committed clock and bind the next original run event or an actual causal Task transition beyond a bounded terminal prefix. The reader generates no schedules or events. Terminal snapshots must carry the exact admitted result digest, complete recorded prefix, coverage and operation count. Recorded breakpoint resolution is checked against the admitted plan and supported points; unsupported requests stay unresolved. Original fixed-task inspections must match exact typed Task inputs, observed prefix state and bounded prerequisite/lag reasons. No evaluated output values or Test PASS is inferred.

## Workbench

The explicit recorded-debug example first loads Source, then the existing recorded simulation, then debugger frames. Previous/next selects an already captured frame. Ready, Paused and Terminated remain distinct; committed clock, future pending transition, breakpoint resolution, fixed defaults, waiting reasons and recorded prefix are inspectable. Original pending/inspection/event locations navigate through the current scoped Source map.

Current run/source identity and load generations fence all reads. Context change, permission loss, Source reload, run reload and modified original bytes withdraw frames and targets. Selection and navigation accept only current admitted frame and original location objects; copied/old frame handles cannot become targets. Keyboard navigation focuses the selected frame, and context/permission changes invalidate delayed focus. English and Japanese labels use the existing product i18n mechanism.
