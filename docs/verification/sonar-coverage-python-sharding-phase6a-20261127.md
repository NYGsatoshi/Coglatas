# Phase 6a: native Python coverage partition qualification

Based on #2278 at `1b2a2f8d763a6c05435ea4976d6b877c6bc1db56`. [Successful scanner run 45913402906](https://github.com/NYGsatoshi/Coglatas/actions/runs/45913402906/job/140226964571) recorded a 486-second Python/GCP producer. The existing Python loop has 68 controls: 67 unittest suites (1,490 tests, 343.686 seconds of reported unittest time) and a separate AV-MIG production CLI mutation driver (roughly 100 seconds). GCP's 11 tests are a distinct native coverage cohort, not part of these 1,490. The largest measured unittest controls were assignment transition (72.990 s), local performance (62.924 s), and main runtime artifact (54.186 s). The final CLI driver executes real mutation probes and must not be lost merely because it does not print a unittest summary.

Initial two-lane partition derives from greedy assignment of the actual prior unittest durations, per-control startup estimates and final CLI runtime (roughly 230.8 / 231.0 seconds estimated, not measured on new runners). The complement includes new controls; a removed/renamed pinned partition member fails closed. Every lane uses the original reviewed Bash dispatch body from the production workflow and the same checksum-pinned pure Python coverage.py wheel, branch/parallel configuration and opt-in child-process bootstrap. Baseline executes all 68; shard union must exactly reproduce the canonical control set, per-control all-passed unittest totals, and original AV-MIG mutation identities/outcomes. Unittest's existing nonverbose output does not expose individual method identities; the proof does not claim method-level equality beyond the exact unchanged suite invocation and counts.

Retain all original native process shards, lane data/XML/JSON, actual mutation ledger and identity/hash/timing receipts. Join uses coverage.py's own native combine of the two consolidated native data files, generates native XML/JSON, and demands identical baseline tracked source, executed lines and arcs, JSON file/branch evidence, and XML except its generation timestamp. No hand-authored coverage union, threshold/exclusion changes, credential policy expansion, or changes to actual authenticated workflow. GCP stays unchanged. A pilot also runs baseline so it is not a production speedup; measure actual durations and compute overhead before proposing production adoption.

The proof is credential-free, on a dedicated same-repository stacked PR. The existing trusted Sonar router remains Main-target only. All native and static checks must pass; actual publication would need a separate staging trial. Main untouched.
