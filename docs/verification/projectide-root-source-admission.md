# Root Source diagnostic premise admission (#1034)

This partial Product slice adds explicit admission of the retained root Source
when complete regional binding/graph/IR is unavailable. It pairs Angular with
the Windows pure ViewModel; actual Avalonia and current backend authority are
separate. A local read starts no Compiler, run, external operation or live write.

ProjectRootSourceAdmission binds the actual owned compilation and accepted
result object, expected result digest, exact input and original Source bytes.
Root admission is bounded to the existing4MiB source-transport limit; it does
not adopt a durable storage quota. Copied equal-ID results cannot substitute.
Root premise reading accepts only an owned finding in the root context and
searches root Compiler input and root Source objects. The metadata explicitly
records bodyScope=RootCompilerInputObjects; complete regional evidence or IR
coverage is not implied. Existing regional admission remains a separate path.

The additional RootSource body kind uses coglatas.project-source/1 and the exact
original retained SourceJson bytes. Default Manifest has no bodies; available
reads reuse the provisional1MiB/32MiB body budget and atomically retain zero on
aggregate overflow. Root input/Source hashes do not reconstruct an unrecorded
predicate-premises body, earlier states, AND/OR or causal relationships. Those
gaps and all original Compiler result axes remain visible and unchanged.

The distinct --root-diagnostic-premises exporter replays four actual legacy Core
inputs with their original input/Source/result identities, including real failure,
missing evidence and mixed diagnostic cases. Its root projection contains original
native input/result text frames and binds existing sourceText; it does not create
a second serialization of parsed Source data. The thirteen earlier deterministic
profiles and the twelve-case regional premise profile must remain byte-identical.
This local candidate format is not Registry/Trust/Eligibility adoption.

Both client adapters require explicit current Source admission before reading
premises. Source readmission, new inputs, selection/result changes, reset/disposal,
newer reads and existing actor/Tenant/Workspace withdrawal prevent old publication.
A failed regional read also withdraws the root admission. Angular checks package
membership and every metadata variant, freezes its admitted original data, and
rejects copied admission tokens, foreign findings and payload mutation across
awaited hashes. Body availability, current access, evidence completeness and
result meaning remain independent. Retained caller objects are not deletion.

Product native and Angular tests use actual Core/exported original frames, including
atomic exact/last-byte bounds, copied result/finding identity, cancellation,
notification reentry, new lifecycle generations, stale and newer reads, mixed
missing evidence, rehashed metadata alterations, both locales and focus behavior.
The real production static browser suite must separately qualify this profile.
Product checks and static packages do not prove runtime query/open/export access,
revocation/redaction/deletion or independent Security acceptance; P0 #1966/#1932
owns those boundaries. Shared exporter/selection coverage stays P0 #1959, and
shared CI lifecycle remains P0 #1974. No Security branch/shared CI changes here.
